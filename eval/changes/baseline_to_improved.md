## 변경 이력: baseline → improved

### 비교 기준

| 항목 | baseline | improved |
|---|---|---|

| 검색 방식 (`RETRIEVER_MODE`) | `baseline` (순수 벡터 RAG) | `current` (오류코드 안내 페이지 청크 우선) |

### 변경 사항 (app.py)

| # | 영역 | 변경 내용 | 코드 위치 | 발견 계기 (baseline 문제) | 대상 질문 |
|---|---|---|---|---|---|
| 1 | 검색 | 오류코드 안내 페이지 청크 우선 적용. 질문의 오류코드(UE, IE, OE 등)를 찾아 `ERROR_PAGES`의 안내 페이지에서 코드가 적힌 청크를 Top-K 앞에 넣음. **코드는 baseline 커밋에 이미 있고, 검색 방식 설정만 `baseline`→`current`로 바꿈** | `WasherManualRetriever` (`use_code_priority=True`), `build_retriever` | 복합 질문에서 UE 안내(55쪽)를 찾지 못함 | Q08 |
| 2 | 검색 | **1E를 IE로 인식.** `CODE_PATTERN`에 `1E` 추가(앞이 숫자인 경우 제외하도록 lookbehind를 `(?<![A-Za-z0-9])`로 변경), `ERROR_PAGES`에 `"1E": [55, 40]` 추가, `CODE_TEXT_ALIASES`에 `IE`·`1E` → `[I1]E` 추가(청크 본문의 'IE'와 40쪽 원문의 '1E'를 모두 코드 청크로 인정) | `ERROR_PAGES`, `CODE_PATTERN`, `CODE_TEXT_ALIASES` | 표시창의 IE를 고객이 '1E'로 말하면 오류코드로 인식하지 못해 정답 문서가 7위 | Q05 (Q07도 40쪽 '1E' 청크를 코드 청크로 인정) |
| 3 | 상담 흐름 | **사용법 질문을 차단하지 않음.** 범위 분류 스키마 `ScopeDecision`에 `is_usage_question` 필드 추가, `SCOPE_PROMPT`에 "통살균·세탁 코스·세제·고무패킹·거름망 청소 등 기능·관리 문의도 제품 이름이 없어도 '워시타워 세탁기'" 규칙과 `is_usage_question` 정의 추가, `consult()`의 증상 되묻기 조건에 `not scope.is_usage_question` 추가 | `SCOPE_PROMPT`, `ScopeDecision`, `consult()` | 통살균 주기 질문을 '증상 없음'으로 보고 증상을 되물으며 차단 | Q02 |
| 4 | 답변 생성 | **시스템 프롬프트에 사용법 질문 규칙 추가.** 막거나 증상을 되묻지 말 것, '워시타워 세탁기 기준'으로 안내한다고 밝힌 뒤 설명서 내용을 바로 설명할 것, route는 '자가 점검 우선' | `SYSTEM_PROMPT` | 위와 같음 | Q02 |
| 5 | 답변 생성 | **시스템 프롬프트에 IE 정의 규칙 추가.** IE(1E로 보일 수 있음)는 정해진 시간 안에 물이 설정 수위까지 채워지지 않을 때(수위 센서가 일정 수위를 감지하지 못할 때) 나타나는 급수 이상 신호임을 먼저 설명하고, 수도꼭지 잠김·단수·호스 꺾임·동결·거름망 막힘은 원인 후보로 안내. 특정 원인을 IE의 의미로 단정하지 말 것 | `SYSTEM_PROMPT` | IE를 "거름망이 막혔을 때 나타나는 코드"처럼 설명 | Q05, Q07 |
| 6 | 답변 검사 | **IE 정의 검사 추가.** 질문에 IE/1E가 있는데 답변에 물 미충수·수위·급수 이상·수위 센서 설명이 없으면 피드백과 함께 한 번 재생성 | `review_answer()` → `issues["ie_definition"]` | 위와 같음 | Q05, Q07 |
| 7 | 고정 안내 문구 | **IE 정의 고정 문구 추가.** 재생성 후에도 6번 검사에 걸리면 IE 정의와 원인 후보를 담은 고정 문구를 답변 끝에 덧붙임 | `SAFETY_NOTES["ie_definition"]` | 위와 같음 | Q05, Q07 |

앱 동작과 무관한 평가 도구 변경: `eval/compare.py`가 결과 파일 2개 이상을 받도록 일반화하고, 답변 비교 표에 검색 결과 동일 여부와 답변 텍스트 유사도를 추가함.
