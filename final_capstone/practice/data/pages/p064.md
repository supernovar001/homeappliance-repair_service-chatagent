# 세탁기/건조기 공통

## 와이파이

|증상|원인 및 해결책|
|---|---|
|**가전제품과 스마트폰을**<br>**Wi-Fi로 연결할 수 없어요.**|**스마트폰에 연결된 Wi-Fi 비밀번호가 맞지 않나요?**<br>• 스마트폰 Wi-Fi 설정 메뉴에서 사용 중인 Wi-Fi 신호를 찾아 ‘네트워크 지우기’ 선택한<br>후 제품 등록을 처음부터 진행하세요.|
|**가전제품과 스마트폰을**<br>**Wi-Fi로 연결할 수 없어요.**|**스마트폰의 자동 네트워크 연결 기능이 설정되어 있나요?**<br>• 스마트폰의 모바일 Wi-Fi 설정 내의 고급 항목 (더보기)에서 ‘**모바일 데이터 자동 전환**’,<br>‘**스마트 네트워크 전환**’, ‘**패스포인트**’, ‘**인터넷 사용 불가**’ 항목이 있다면 체크<br>해제하세요. 단, 제조사/통신사마다 항목 이름이 다를 수 있습니다.|
|**가전제품과 스마트폰을**<br>**Wi-Fi로 연결할 수 없어요.**|**스마트폰의 ‘모바일데이터’를 사용 중인가요?**<br>• 스마트폰의 모바일 데이터를 끄고, Wi-Fi로 제품 등록을 하세요.|
|**가전제품과 스마트폰을**<br>**Wi-Fi로 연결할 수 없어요.**|**구형 무선 공유기를 사용 중인가요?**<br>• 구형 무선 공유기*1의 이름이나 비밀번호에 한글 또는 한글+한자키 조합의<br>특수문자(★, □, ■, ♥ 등)가 포함되어 있으면 제품을 무선 공유기에 연결할 수<br>없습니다. 와이파이 이름과 비밀번호는 반드시 영문이나 숫자, 혹은 영문과 숫자<br>조합으로 설정하세요.<br>*1 구형 무선 공유기는 유니코드(전 세계의 모든 문자를 다루도록 설계된 표준 문자<br>전산 처리 방식) UTF-8을 지원하지 않는 공유기입니다.|
|**가전제품과 스마트폰을**<br>**Wi-Fi로 연결할 수 없어요.**|**공유기 주파수가 2.4 GHz가 아닌가요?**<br>• 제품 연결 시 2.4 GHz 네트워크만 지원합니다. 무선 공유기를 2.4 GHz로 설정한 후<br>연결하세요. 공유기 주파수 확인하려면 통신사 또는 공유기 제조사를 통해 확인하세요.|
|**가전제품과 스마트폰을**<br>**Wi-Fi로 연결할 수 없어요.**|**가전제품과 공유기가 멀리 떨어져 있습니다.**<br>• 가전제품과 공유기 사이 거리가 먼 경우 신호가 약해 접속이 원활하지 않을 수<br>있습니다. 공유기 위치를 이동하여 제품과 가까운 거리를 유지하세요.|
